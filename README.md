# AI-Based Interview Evaluation System

## Description
This project is a web-based AI system that evaluates candidate interview responses using NLP and voice recognition.

## Features
- Text and voice-based interview system
- AI-based answer evaluation
- Score generation with feedback
- Automated report generation

## Tech Stack
- Frontend: React
- Backend: Flask
- AI: NLP, Speech-to-Text

## My Contribution
- Implemented backend logic using Flask
- Developed AI-based evaluation mechanism
- Integrated response analysis and scoring

## How to Run
1. Clone the repository
2. Install dependencies
3. Run backend and frontend servers
